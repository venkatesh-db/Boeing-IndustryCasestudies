🧭 Remember

Overlap = a data problemVersions, unique IDs, effective dates, metadata filters before search, a cap per document. Ranking tweaks will not tell STANDARD from PLUS.
Overfitting = an eval problemKeep a held-out set you never tune on. A fix that only turns the failing test green is not a fix.
Hybrid search helps with neitherIt merges two rankings. It cannot know Maria’s plan, today’s date, or what real customers will type next.
