🧪 Run the real labs yourself

Every number in these pages came from these scripts. They need Ollama with llama3 running locally and the AeroGuard virtual environment.
cd Deployed-Products/labs
../../aeroguard/.venv/bin/python overlap_experiment.py   # wrong-hospital answer, then metadata filters
../../aeroguard/.venv/bin/python overfit_experiment.py   # dev set vs 8 held-out questions
LabWhat it provesOutput
overlap_experiment.pyWithout plan and year filters, lines from other plans and from the old year reach the answer. Filtering before search fixes it.overlap_results.json
overfit_experiment.pyA fix that passes the one failing eval case can still fail new wordings. Only a held-out set shows this.overfit_results.json
